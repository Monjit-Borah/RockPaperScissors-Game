# 🎮 Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors** web game built using **HTML, CSS, and JavaScript**.  
Play against the computer and test your luck with this classic game!

---

## 🚀 Live Demo  
🔗 [Click here to play](https://monjit-borah.github.io/RockPaperScissors-Game)

---

## 📌 Features

- 🧠 Computer generates random moves  
- 🎨 Clean and responsive UI  
- ⚡ Instant result display (Win / Lose / Draw)  
- 📱 Works on desktop and mobile devices  
- 🎯 Beginner-friendly JavaScript logic  

---

## 🕹️ How to Play

1. Select **Rock**, **Paper**, or **Scissors**
2. The computer will choose randomly
3. Game rules:
   - Rock beats Scissors  
   - Paper beats Rock  
   - Scissors beats Paper  
4. Same choice → Draw
